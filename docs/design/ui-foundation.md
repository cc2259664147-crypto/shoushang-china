# M03 首发视觉与交互基线

2026-10-17；先确定此基线，再实现组件。仅用于基础 UI，后续由总控统一调整。系统中文字体："Microsoft YaHei", "PingFang SC", system-ui, sans-serif；无网络字体或远程图标。

## 颜色与对比度

以 WCAG sRGB 相对亮度公式 `(L亮+0.05)/(L暗+0.05)` 测量，浏览器验证脚本重新计算并记录精确结果。所有颜色集中在公开样式的 `.ss-theme` token 作用域，可由消费端覆盖，不修改全局 :root/body。

| token（均以 --ss- 开头） | 色值 | 用途 / 配对 |
| --- | --- | --- |
| paper | #f6f1e7 | 宣纸页面底色 |
| surface | #ffffff | 内容与控件表面 |
| ink | #252521 | 正文 / surface 15.38:1，paper 13.66:1 |
| muted | #62625b | 辅助正文 / surface 6.14:1，paper 5.46:1，soft 4.94:1 |
| primary | #a82d26 | 朱红主按钮白字 / surface 6.84:1 |
| primary-hover | #8d241e | 主按钮悬停 / 白字 8.74:1 |
| primary-active | #721c17 | 主按钮按下 / 白字 11.09:1 |

以上数值来自最终真实浏览器读取主题变量后的sRGB计算，原始结果见`prototypes/ui-preview/evidence/browser-report.json`。大号文字沿用满足正文要求的颜色。焦点使用外偏移，避免紧邻朱红控件本身而影响识别。

禁用仍保留可读文字，以虚线边框、浅底、禁止光标共同标识，不单靠透明度。所有信息/成功/警告/错误均提供文字前缀。

## 尺度

字阶：小字14px / 1.5，正文16px / 1.6，三级标题20px / 1.4，二级28px / 1.3，一级36px / 1.2；小屏一级28px。组件继承主题字体，输入不小于16px。间距 token 为4、8、12、16、24、32、48px；控件最小高度44px，图标按钮44×44px，圆角8px、弹窗16px，边框1px。

## 状态与动作

交互焦点使用3px实线和3px外偏移，不移除浏览器焦点而无替代。悬停改变表面，按下加内阴影；禁用与加载阻止触发。加载保留原按钮名称与尺寸，以绝对定位状态图形替换视觉文字，aria-busy与独立polite状态说明等待。

错误具有文字、关联描述和 aria-invalid；label与必填文字不依赖placeholder。NumberInput保留原生字符串/空值语义，以数值快照及validity交给调用方，提交才校验业务约束。

原生dialog以showModal进入top layer，背景inert行为由浏览器提供。初始焦点优先指定元素，否则关闭按钮；关闭恢复触发元素，消失则聚焦调用方后备或主题容器。不支持嵌套。确认等待期间禁止取消、Escape和关闭；失败保留内容，错误可重试。危险确认默认聚焦取消。

颜色/阴影过渡120ms，旋转1000ms；不使用位移动画。prefers-reduced-motion: reduce下禁用过渡和旋转，以静态图形及文字保留加载含义。预览的页面网格、背景与原生元素样式由预览工程负责；组件CSS选择器全部限定ss-类名。
