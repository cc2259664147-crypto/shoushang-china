# M13 内容后台与权限

## 负责目录

apps/web/src/features/admin/；apps/api/src/admin/；docs/handoffs/M13.md。仅允许修改列明范围；其他目录只读。独立模块交付可新增本任务的 handoff 文件。若任务路径尚不存在，可在授权范围创建。所有清单、锁文件、contracts、全局样式、路由、组合根与服务挂载由总控统一维护，M01 总控除外。

## 输入

M12数据库/发布查询、PRD角色和发布校验、公共UI。先读 AGENTS.md、docs/contracts/data-model.md、docs/contracts/module-api.md 和依赖任务交接；需求基线为代码根目录上一级的 Markdown PRD。

## 输出

服务端会话、角色、草稿修订/审核/发布/下架、媒体台账、审计；后台页面。跨包只走公开入口；提供有意义的合法、非法和故障验证，不能用空组件或固定成功响应代替行为。

## 依赖

M03、M12；跨目录服务挂载由总控。依赖未具备时报告阻塞或用已授权 mock 进行隔离开发，明确区分已验证与待联调。不得自行安装依赖或改变公共契约。

## 禁止修改范围

不在前端/README放账号密码；proofRef与凭据不得进公开DTO；不修改contracts或直接重构M12模块。不扩展到注册、云同步、支付、评论或多技艺编辑器；不修改其他任务文件或原始资料。

## 完成标准

401/403不可绕过；草稿不泄漏；修订冲突/幂等；授权检查；媒体真实格式/尺寸/5MB限制；Cookie/CSRF/密码摘要；重启保留。运行与本任务相关的验证，最终由总控执行 pnpm typecheck/test/build 并整合。不得为占位编写无意义验收，不能宣称未实现能力通过。

## 交付说明要求

在 docs/handoffs/M13.md 记录：实际改动文件、公开入口/输入输出、依赖和契约变化提案、真实执行的命令与结果、异常/边界用例、仍未验证能力、待总控整合项、下一接手条件。完成后停止，不自动开始下一模块。
