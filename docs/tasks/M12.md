# M12 真实内容服务与 HTTP 访问层

## 负责目录

apps/api/src/content/；apps/api/src/database/；packages/content-client/src/；docs/api/；docs/handoffs/M12.md。仅允许修改列明范围；其他目录只读。独立模块交付可新增本任务的 handoff 文件。若任务路径尚不存在，可在授权范围创建。所有清单、锁文件、contracts、全局样式、路由、组合根与服务挂载由总控统一维护，M01 总控除外。

## 输入

公共模型/ContentClient、PRD公开接口、Node SQLite 能力。先读 AGENTS.md、docs/contracts/data-model.md、docs/contracts/module-api.md 和依赖任务交接；需求基线为代码根目录上一级的 Markdown PRD。

## 输出

SQLite迁移与已发布查询、HTTP适配器、响应schema校验、OpenAPI和备份恢复说明。跨包只走公开入口；提供有意义的合法、非法和故障验证，不能用空组件或固定成功响应代替行为。

## 依赖

M01；接口整合由总控挂载至app.ts。依赖未具备时报告阻塞或用已授权 mock 进行隔离开发，明确区分已验证与待联调。不得自行安装依赖或改变公共契约。

## 禁止修改范围

不改app.ts/server.ts、contracts、依赖清单或后台账号逻辑；不上传访客本地作品。不扩展到注册、云同步、支付、评论或多技艺编辑器；不修改其他任务文件或原始资料。

## 完成标准

数据重启保留；发布过滤与详情一致；查询分页稳定；超时/取消/网络错误遵守端口；mock/http同契约；恢复演练。运行与本任务相关的验证，最终由总控执行 pnpm typecheck/test/build 并整合。不得为占位编写无意义验收，不能宣称未实现能力通过。

## 交付说明要求

在 docs/handoffs/M12.md 记录：实际改动文件、公开入口/输入输出、依赖和契约变化提案、真实执行的命令与结果、异常/边界用例、仍未验证能力、待总控整合项、下一接手条件。完成后停止，不自动开始下一模块。
