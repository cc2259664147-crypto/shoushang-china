# M15 专业剪纸编辑器

状态：M15-0 设计完成，等待总控审核；M15-1～M15-8 均未开始。日期：2026-10-23（Asia/Shanghai）。

## 总目标与边界

在不破坏 V1.0 作品、存储和导出链路的前提下，把现有参数化工坊演进为桌面优先、窄屏可完成核心操作的轻量级专业剪纸编辑器。第一阶段新增闭合套索自由剪刀、切口选择/移动/删除/清空、完整撤销重做，以及只改变视图的缩放和平移；保留三种参数化形状、折叠/展开、对称复制、本地草稿/完成版、刷新恢复、缩略图和 PNG 作品卡。

本任务的不可变边界：

- `delivery/v1-initial-20261023-final6/` 是冻结交付物。M15 的任何模块均不得修改、覆盖或重新生成该目录；验收必须证明零改动。
- 正式服务器、正式数据库、已部署版本和公开内容均不在 M15 范围内。访客作品继续只保存在当前浏览器。
- 不以背景色遮挡、装饰按钮、未保存路径或另一套几何/渲染实现冒充功能。
- 现有工作区修改和未跟踪文件均视为用户成果。禁止 reset、checkout、clean、stash、删除或覆盖。
- M15-0 只允许新增本文、`docs/design/papercut-editor-v2.md`、`docs/handoffs/M15-0.md`，以及在 `docs/contracts/change-requests.md` 追加待审批提案；不实现业务代码、不安装依赖、不提交、不推送、不部署。
- 后续模块也必须先取得各自明确授权；公共 contracts、清单、锁文件、根配置、组合根和跨模块挂载仍由总控维护。

## 子模块与文件所有权

同一行内标注“可并行”的模块也只能在其独占文件中工作；涉及同一文件或同一公共契约时一律串行。任何模块开始前都要阅读 M15-0 设计、上游交接和当时的 `git status --short`。

## 总体验收条件

- 自由剪刀为闭合套索：实时轨迹与闭合预览可见，提交后是可保存、可展开、可导出的真实镂空；开放式刀路不进入 v2。
- 三种参数化切口继续可用；选择、移动、删除、清空、撤销/重做全部走 core 命令，删除/移动/清空可撤销。
- pan/zoom/fit 不改变作品坐标、历史、revision 或保存状态；输入手势无歧义且可取消。
- v1 作品仍由 v1 schema/geometry/renderer 只读打开、渲染和导出；不原位重解释。另存 v2 使用新 ID，失败保留 v1 原记录。
- folded/unfolded/thumbnail/PNG 共用 Work→core geometry→renderer；重叠孔洞为 union；无脚本、外链或未转义用户输入。
- v1/v2 在 IndexedDB 中共存，revision/草稿/缩略图/冲突语义保持；未知版本和迁移失败记录可检查并导出备份。
