# M06 统一 SVG 作品渲染

## 负责目录

packages/artwork-renderer/src/；docs/handoffs/M06.md。仅允许修改列明范围；其他目录只读。独立模块交付可新增本任务的 handoff 文件。若任务路径尚不存在，可在授权范围创建。所有清单、锁文件、contracts、全局样式、路由、组合根与服务挂载由总控统一维护，M01 总控除外。

## 输入

Work 快照、ArtworkRenderer、M04 几何输出。先读 AGENTS.md、docs/contracts/data-model.md、docs/contracts/module-api.md 和依赖任务交接；需求基线为代码根目录上一级的 Markdown PRD。

## 输出

folded/unfolded 自包含 SVG，供预览缩略图及导出共用。跨包只走公开入口；提供有意义的合法、非法和故障验证，不能用空组件或固定成功响应代替行为。

## 依赖

M01、M02、M04。依赖未具备时报告阻塞或用已授权 mock 进行隔离开发，明确区分已验证与待联调。不得自行安装依赖或改变公共契约。

## 禁止修改范围

不写另一套剪纸算法，不写页面/存储/PNG；通过 core 公开入口。不扩展到注册、云同步、支付、评论或多技艺编辑器；不修改其他任务文件或原始资料。

## 完成标准

同数据同结果；旧版本稳定；不修改输入；裁切/镂空/比例正确；无脚本或外链；未知版本显式失败。运行与本任务相关的验证，最终由总控执行 pnpm typecheck/test/build 并整合。不得为占位编写无意义验收，不能宣称未实现能力通过。

## 交付说明要求

在 docs/handoffs/M06.md 记录：实际改动文件、公开入口/输入输出、依赖和契约变化提案、真实执行的命令与结果、异常/边界用例、仍未验证能力、待总控整合项、下一接手条件。完成后停止，不自动开始下一模块。
