## 状态与并发

核心状态为 `PapercutState`，页面只通过 core.dispatch 执行剪切、配色、撤销、重做。步骤、名称、候选形状属于会话/页面编辑状态；候选未确认时不进入 Work、历史或草稿。位置输入和 Pointer Events 都使用容器实测矩形映射到居中的单位纸张。画布使用 pointer capture，处理 up/cancel，ResizeObserver 跟踪变化；触控滚动仅在画布禁用。

草稿保存采用 700ms 固定延迟且不在连续编辑时重置，按队列串行。`Work.revision`、草稿 `revision`、草稿 `baseRevision`、内存 `generation`、已持久化 `persistedGeneration` 分别维护。只采用仓储返回的实际草稿修订。旧快照保存成功时只提高其对应的持久化代次，继续安排最新内容；完成保存先冲刷草稿，再从同一 Work 快照经 M06 unfolded SVG、Image.decode 和 Canvas 生成 PNG Blob，最后 `commitDraft` 原子提交。提交期间有新编辑时保留当前操作，并为完成版的新修订安排后续草稿。冲突停止自动重试，保留本地内容，提供明确的重新载入或另存新 ID。放弃先取消计时，再排入同一队列，用已取得的最新草稿修订执行 `discardDraft`。

状态文案区分未开始、编辑中、保存中、草稿已保存、作品已保存、保存失败、恢复中。数据库失败保留内存创作，提示无法保存。进入页并行读取草稿列表与 `inspectRecords`；坏记录有错误提醒和原始备份下载，不会静默删除。历史作品通过自身模板快照恢复；已完成作品可按 ID 打开再编辑，自动草稿不覆盖完成版。

站内返回和浏览器后退由 App 与页面 guard 协作，提供保存草稿、放弃、继续编辑。刷新/关闭用 `beforeunload`。浏览器对原生离开提示的展示由浏览器决定，不依赖异步卸载保存。

## M07 审核后修复

阶段审核指出三项 P2。切换确认现在给每次异步操作分配代次；保存等待时点击“继续编辑”使旧回调失效，完成写入仅保留当前草稿，不再切换画布；放弃操作进行中则禁用取消。后退保护在原生 `popstate` 目标条目上等待选择，取消时按历史索引返回工坊，确认时不新增或替换历史条目，因此浏览器前进记录保留。顶部“展开预览”步骤与画布视图同步，恢复预览步骤时也渲染 unfolded 视图；画布旁的双视图按钮同步步骤。

新增真实 Edge 回归：持有 IndexedDB 写锁时取消保存后切换及离开，确认后退再前进，以及读取 M06 内嵌 SVG 验证顶部预览实际使用 unfolded 视图。`.review-m07/` 独立审核资料保持原样；原审核脚本中的切换复现会等待旧缺陷的“0 个切口”，修复后不再适合作为通过命令，使用上述新回归验证正确行为。
