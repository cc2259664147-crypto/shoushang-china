## 组件与公开 API

所有组件及类型从`@shoushang/ui`导出：Button（四种intent）、IconButton、CloseIcon、FormField、TextInput、TextArea、NumberInput、Select、Dialog、ConfirmDialog、InlineNotice、StatusMessage、LoadingState、EmptyState。完整属性表与最小例子见[组件API](../design/ui-components.md)。

消费组合根加载一次`import '@shoushang/ui/styles.css'`并包裹`ss-theme`。表单FormField的render函数属性必须展开至对应单个输入；value/onChange受控，不含业务校验。NumberInput使用字符串value与onValueChange({raw,number,badInput})；空值不转0，中间文本由原生number暂存，不把清洗后的raw误称为完整编辑文本。提交时由调用方处理原生validity和业务规则。

Dialog的open由调用方控制，onClose请求关闭后同步设置false。原生showModal负责背景不可操作，组件补充Tab循环；支持Escape、关闭按钮与native close事件同步。确认默认聚焦取消，等待时禁止取消/关闭并通过onPendingChange通知；成功请求关闭、异常显示polite错误且保留子内容。无后台调用。所有模拟操作均在页面明确标识。

## 限制与后续接入

没有人工屏幕阅读器、Windows高对比/强制颜色、浏览器缩放、真实触控硬件、iOS Safari或Android Chrome验证；自动语义/焦点测试不能证明这些体验全部通过。只验证本机现代Edge，原生dialog需要现代浏览器，不提供旧版polyfill。

不支持嵌套或同时多个弹窗，明确抛错；无复杂自定义下拉、搜索、多选、Shadow DOM焦点系统。ConfirmDialog等待期间不支持取消网络任务，调用方须提供超时并确保Promise结算；pending时不要强制关闭/重开，旧请求副作用不由组件中断。NumberInput中间文本与locale由原生浏览器管理，不保证跨平台相同清洗行为。

正式页面后续只接公开组件/样式入口，自行提供导航、内容、校验和业务端口。正式应用路由及全局CSS本阶段未接入。M02算法冻结、边界保守性、连通性、同view实例ID隔离与真机/性能遗留项继续由后续核心和渲染模块处理，本阶段未修改算法或重复耗时性能采样；本次M02回归范围是类型、17项原测试、构建与服务存活。

## 手动验收清单

1. 打开5175，确认组件演示标识；5173/5174仍可访问。
2. 用Tab与Shift+Tab巡检焦点；Enter/空格触发按钮；加载时连续点按只计数一次。
3. 点击名称label，空提交应有文字错误；数量清空/输入负号再续输，不自动变0；键盘选择材料。
4. 打开普通弹窗，循环Tab，分别用Escape/关闭/完成退出，焦点返回；触发消失示例回到标题。
5. 异步确认先模拟失败，输入保留；等待时不能取消；取消失败勾选后重试关闭。
6. 在360宽、较矮视口打开长弹窗，滚至末尾并关闭；开启减少动态效果后仍可理解等待状态。
