# M08 PNG 作品卡导出交接

## 范围和入口

实现位于 `packages/artwork-exporter/src/index.ts`，保留原有三种类型导出，新增 `createArtworkExporter({ renderer?, resourceTimeoutMs? })`。默认使用 `@shoushang/artwork-renderer` 的公开工厂，也可注入 `ArtworkRenderer`。调用：

```ts
import { createArtworkExporter } from '@shoushang/artwork-exporter';
const result = await createArtworkExporter().exportCard({ work });
if (result.ok) {
  const blob = new Blob([result.value.bytes.slice().buffer], { type: result.value.mimeType });
  // 页面决定预览、下载与 URL 生命周期。
}
```

总控接入仅改 `packages/artwork-exporter/package.json`、`apps/web/package.json`、`pnpm-lock.yaml` 的既有 workspace 链接，新增包内严格 `tsconfig.json`；工坊新增 `WorkCardExport.tsx`，`WorkshopPage.tsx` 只在工具区接入，`workshop.css` 只增加 `.ws-export` 作用域样式，另有 M08 专用浏览器 spec。没有改 session 保存、导航保护、core、renderer、repository、UI、contracts、全局 CSS、路由或根配置。未提交、未推送，原有 `.review-*` 保持不变。

## 输入、版式与日期

第一次异步等待前用 `WorkSchema.safeParse` 取得深复制快照，校验尺寸并调用 renderer 的 `unfolded` 视图。未知 Work、几何、渲染及操作参数版本明确返回 `UNSUPPORTED_VERSION`；renderer 返回的几何与版本错误原样保留。卡片先填充不透明暖纸底色，再按比例居中绘制完整 SVG 图像；Canvas 只合成该图、标题与文字。解码后在透明的 16×16 探针 Canvas 上绘制 SVG，检查内嵌图像实际产生全幅不透明像素；不要求仍有纸色，因此合法全镂空作品也可导出。标题按 Canvas 实测宽度以 grapheme 分段，至多两行，第二行超出用省略号；不改 Work 原名。正文含工艺、数字体验和实体剪裁说明、手上中国署名，不含内部 ID 或身份。

日期取同一快照的 `updatedAt` 并按 `Asia/Shanghai` 转换，不取导出时钟。仅 `status=completed` 且 `revision>0` 使用“创作日期”；其余标明“草稿 · 作品时间…（尚未保存）”。文件名为 `手上中国_安全名称_YYYY-MM-DD.png`，清理控制字符、路径和 Windows 非法字符，限制名称 40 个 Unicode 码点，空值使用“未命名作品”；这不改变作品名。UTC 与带 offset 的跨日输入已实测。

默认尺寸 1600×2000；宽 600–4096、高 750–4096，均须安全整数；高度为宽度的 1.05–2.5 倍，总像素至多 1200 万。无静默缩放。字体、SVG 图像解码、PNG 编码与读取分别设置 8 秒等待上限。资源失败为 `RESOURCE_UNAVAILABLE`，Canvas 或编码失败为 `EXPORT_FAILED`，输入失败为 `INVALID_INPUT`，均含 requestId 和 fieldErrors。失败可重试，不更改 Work、revision、时间或 IndexedDB。

## 字体和手机

字体资源 `src/fonts/NotoSansSC-Regular.otf` 是本机已安装 Noto Sans SC Regular OpenType 2.002 的未修改复制件，大小 8,482,020 字节；字体自身 name table 记录 SIL OFL 1.1，随包保留官方 `OFL.txt` 和 `SOURCE.md`（来源、版本、原许可链接）。构建生成约 8.48 MB 的字体资源。显式 `FontFace.load()` 和 `document.fonts.check()` 后才绘制，失败不冒充已加载。常见简体中文及拉丁文字可用；稀有字和 emoji 彩色字形不保证由此字体覆盖，浏览器可能使用系统缺字回退，不能据此宣称完整字形覆盖。运行时无远程字体请求。

工坊生成按钮独立于 M07 的 busy，ref 同步互斥；生成中可取消，失败保留上次可用结果，作品切换及卸载使旧任务失效。旧 Blob URL 在结果替换或组件卸载后释放；预览、下载和“打开图片”共享同一 URL 与 bytes。桌面显式下载，手机提供打开图像及长按保存说明。下载触发只提示“作品卡已生成”，不宣称已落盘或入相册。未做真机长按与不同手机浏览器的相册行为验证。

## 验证和证据

命令：`pnpm typecheck`、`pnpm test`、`pnpm build`、`pnpm exec tsc --noEmit -p packages/artwork-exporter/tsconfig.json`、`pnpm exec playwright test --config apps/web/src/features/workshop/playwright.config.ts work-card-export.m08.spec.ts`、同配置的 `workshop.spec.ts`。M08 browser spec 位于工坊授权目录，后缀 `.spec.ts` 不进入根 Vitest。M07 17 项回归截图测试期间临时备份，运行后恢复。

最近一次结果：Vitest 8 文件 67 项通过（M08 8 项）；M08 Edge 专项 10 项通过；M07 Edge 17 项通过；类型检查与 Web/API 构建通过。Edge 下载文件和预览 bytes 完全相同。PNG 实测 1600×2000、全图 alpha=255、四角底色 `#F8F3E9`、纸色 `#B82025`、镂空 `#FFFFEE`；完整 SVG 内嵌图像在实际 PNG 可见。已人工打开检查 `src/browser/evidence/sample.png`，并保留 `desktop.png`、`narrow.png`、`report.json`。失败注入覆盖字体拒绝、图像拒绝与超时、Canvas 不可用、编码失败及后续重试；这些是模拟故障，不能当作真实设备故障。窄屏视口是 Edge 模拟，不是真机。

性能为本机 Edge 默认尺寸 `exportCard` 整段耗时，包含字体准备、SVG 解码、合成与 PNG 编码，不含页面启动：冷启动 169.2 ms；预热原始样本 46.1、77.6、46.3、62.3、63.0 ms，中位数 62.3 ms。仅一台本机、一次冷启动，不能推广到低性能手机；未观测超过 10 秒的真实生成，生成中状态及失败重试已验证。

已验证 vertical/radial4、三形状与旋转、无切口及 50/100 个合法切口、停用模板可由历史快照传入、未知版本、非法尺寸及损坏 Work、字体准备后断网导出、双击互斥、切换作品旧结果失效和失败保留旧图。尚未做真实手机相册保存、跨浏览器色彩管理、长期性能及极端内存设备验证。M09 可复用此工厂对本地合法 Work 调用 `exportCard`，由其页面自行管理 Blob URL；接入前需保持 Work 快照、renderer 与本字体资源可用。
