## 公开入口和调用

```ts
import { createArtworkRenderer } from '@shoushang/artwork-renderer';
const result = createArtworkRenderer().render({work, width: 400, height: 300, view: 'unfolded'});
if (result.ok) {
  // result.value: {svg, width:400, height:300, rendererVersion:1}
  image.src = `data:image/svg+xml;charset=utf-8,${encodeURIComponent(result.value.svg)}`;
} else {
  console.error(result.error.code, result.error.fieldErrors);
}
```

输入为完整 Work 快照。唯一几何来源是 core 公开 `getWorkGeometry`。渲染直接用 `localShape` 的三角顶点、椭圆半径或原始三次贝塞尔曲线，以及 `placement`、`symmetryTransforms`、`baseDomain`；SVG 的嵌套变换先执行 placement 再执行 symmetry。没有使用校验用 `conservativeContour` 作路径或重推控制点。成功不修改 Work、时间、revision、模板或操作。

## 视图和镂空

保存坐标始终为 `[0,1]²`，输出取 `scale=min(width,height)`，横纵剩余空间各居中。两个视图共用完整单位方纸视口，不对折叠域另行放大：unfolded 白色 mask 域为完整方纸并使用全部 core 对称矩阵；folded 白色 mask 域为 core 的 `baseDomain`，只使用第一个恒等矩阵及原始切口。vertical 为左半纸，radial4 为右下四分之一；域外显示背景。这样同一保存坐标在两图中的像素位置可以直接比较。

SVG 内置背景矩形、纸张矩形及亮度 mask。白色域保留 `palette.paper`，每条切口及其副本以黑色覆盖 mask，最终露出 `palette.background`。黑色形状互相覆盖仍为黑色，因此重叠镂空取并集，不受 evenodd 重叠填回影响。没有 Canvas、页面 CSS 依赖、远程图片、网络、字体、脚本、事件属性或用户名称 XML 插入；颜色已由 core Work schema 校验为 HEX6。

返回的外层 SVG 用唯一一幅**内嵌** `data:image/svg+xml` 绘制层；绘制层是独立 SVG 图像文档，mask 的 `url(#ss-mask)` 只在该文档内解析。外层没有文档级 fragment ID；没有外部图片或网络请求。相同输入仍返回完全相同的字节，且每次内联挂载由浏览器提供独立图像资源作用域，无需时钟、随机数、计数器或调用方实例键。同 work.id/view 不同颜色或几何、完全相同作品重复挂载都不会引用别的 SVG 的 mask。代价是 URI 编码使输出比初版大，SVG DOM 中外层内容不可直接逐形状编辑；调用方编辑后须重新调用 render。

Edge 实测同页四份 SVG：原图、仅换色、仅改几何、完全重复；还覆盖前一相同 SVG 的父容器 `display:none`、SVG 自身 `display:none`、零尺寸容器及显示后动态隐藏，第二份孔洞始终保留。独立 `<img>` 数据 URL 加载也通过像素检查。此处验证范围为 Edge 155；其他浏览器和将 SVG 内容任意后期改写的情况尚未验证。

## 版本与错误

尺寸运行时要求正的安全整数，view 只接受 folded/unfolded；缺失或无效值返回 `INVALID_INPUT`，有 `requestId` 和 `fieldErrors`。完整 Work 交给 core 校验：结构或参数损坏为 `INVALID_INPUT`，不可剪几何为 `GEOMETRY_INVALID`，未知 schema/geometry/parameter/renderer 正整数版本或暂不支持纸形与对称组合为 `UNSUPPORTED_VERSION`。不按新算法回退。仅支持 core 已实现的方纸、vertical、radial/4/mirror=false 与三种形状。历史作品直接使用自身 `templateSnapshot`，`enabled=false` 和合法旧内容版本不阻止查看；不查询在线模板。
