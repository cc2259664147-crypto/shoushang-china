## 数据与事务

默认 `shoushang-local-v1`，当前物理版本 3：`works(id, updatedAt 索引)`、`drafts(workId)`、`draftRevisions(workId)`、`thumbnails(workId)`、`favorites(exhibitId)`。Work.schemaVersion、数据库版本、模板版本、完成版 revision 和草稿 revision/baseRevision 各自独立。作品及对应 ready/pending 缩略图在同一 readwrite 事务写入；无新图时原子标 pending，不把旧图展示为新版本。`rebuildThumbnail` 比较当前完成版修订。草稿自动保存独立于完成版，提交在同一事务写完成版和缩略图、删除旧草稿；删除完成版同事务删除草稿及图。步骤存在草稿会话，不进入剪纸几何。

修订读取、比较、100 个不同 workId 检查和写入均在同一 readwrite 事务；完成事件后才返回成功。完成版和草稿同 ID 占一个名额，只有新草稿也占一个，损坏键仍计数；收藏不计数。新建 `expectedRevision=null` 首次 revision=1；更新须匹配，已删除目标不复活。草稿同时检查自身修订和基于的完成版修订。时钟回拨时以旧更新时间加 1ms 保证单调，createdAt 保持原值。

读写均通过 M04 `createPapercutCore().validate`；未知作品版本 `UNSUPPORTED_VERSION`，结构/几何非法 `INVALID_INPUT` 并保留 fieldErrors；冲突 `REVISION_CONFLICT` 含预期/实际，存储打不开/权限/阻塞/关闭 `STORAGE_UNAVAILABLE`，作品数与真实配额 `QUOTA_EXCEEDED`。普通列表只包含可用 Work，页面必须同时调用 `inspectRecords` 提醒损坏/不兼容记录；`exportRawBackup` 保留原始结构化数据和 Blob，验证页下载时编码图片 data URL。异常记录不会被修复时静默删除。收藏 put 保留首次 createdAt、remove 重复调用仍成功；只存展品 ID 引用。

物理 v1 仅支持两个名称明确为 `m05-test-legacy-*` 的迁移演练 store；它不是已发布旧版本。坏记录使升级事务回滚并保留 v1 数据。物理 v2 是本阶段之前的开发布局，升级至 v3 保留作品和草稿、提高在库草稿修订；高于当前的数据库版本返回 `UNSUPPORTED_VERSION`，不删除重建。`versionchange` 关闭连接并调用通知；打开阻塞有超时，旧标签关闭后可重试。

## 接入与限制

M07 调用方应在几何/颜色变更后 1 秒内安排 `saveDraft`，展示“保存中”，仅在结果 `ok` 且事务 complete 后展示“草稿已保存”及 `updatedAt`。失败需保留当前画布和可重试状态；完成保存前在事务外准备 M06 的正式缩略图，再 `commitDraft`，若图片生成失败可明确提交 pending 并安排按修订重建。离开/取消编辑使用 `discardDraft` 并带草稿修订；打开草稿须恢复 `step`。多标签页冲突提供读取最新或由页面显式另存独立 ID 的操作，仓储不自行换 ID。

M09 列表并行调用 `list` 与 `inspectRecords`，显示可用作品及损坏/不兼容数量，并提供 `exportRawBackup` 下载。草稿入口用 `listDrafts/readDraft`；卡片只在 `readThumbnail.state='ready'` 且修订一致时显示图，pending 显示待重建。删除仍需页面二次确认，成功后刷新；`close` 在卸载时调用，遇 versionchange 提示刷新。

未验证真实设备配额耗尽、手机/隐私模式、清除浏览器网站数据后的恢复、长期多版本正式发布迁移和 M06 正式图像质量。验证页是开发工具，5176 与正式 5173 来源隔离；不会自动上传或接入正式页面。原始备份仅供保留资料，未提供任意文件导入。普通列表保持 Page<Work> 因而不含损坏条目，使用方必须同时调用恢复接口，不能仅据空列表宣称没有数据。
