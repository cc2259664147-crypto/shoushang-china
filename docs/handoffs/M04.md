## 公开入口与示例

```ts
import { createPapercutCore, getWorkGeometry } from '@shoushang/papercut-core';
import type { PapercutState, PapercutCommand, Work } from '@shoushang/papercut-core';
const core = createPapercutCore();
const initial = core.createState(work); // Work及ID/时间由调用方提供
if (initial.ok) {
  const next = core.dispatch(initial.value, { type: 'add-cut', operation });
  // operation.order为当前operations.length，id由调用方生成。
}
const checked = core.validate(work);
const geometry = getWorkGeometry(work);
```

兼容导出PapercutCore/PapercutState/PapercutCommand/CoreError，以及Work/CutOperation/TemplateVersion/Result；额外纯几何类型Point/AffineTransform/Cubic/LocalShape/CutGeometry/WorkGeometry和只读GEOMETRY_TOLERANCES/HISTORY_LIMIT。输入输出均为纯数据与Result，无渲染字符串、DOM ID、Canvas或隐式副作用。

M05：读取/恢复后调用validate；失败保留原记录并呈现fieldErrors，未知版本与损坏参数分开处理。成功validate返回独立Work；打开作品通过createState清空历史。存储事务、迁移和恢复界面仍由M05实现。保存成功可用`{ ...state, work: savedWork }`保留编辑历史，只要身份与模板快照保持相同。

M06：getWorkGeometry先验证完整Work，输出原始localShape（直线多边形/椭圆/两段三次贝塞尔）、placement、symmetryTransforms、baseDomain及另列的conservativeContour。单位为纸边长；矩阵x'=a*x+c*y+e、y'=b*x+d*y+f；组合顺序symmetry(placement(localPoint))。保守点已应用placement，不能当作正式曲线路径。M06直接渲染原曲线和变换，无需重推公式；处理union镂空语义及实例资源隔离。

## 支持范围、算法和CR

仅单位方纸、reflection/vertical及radial/4/mirror=false；triangle、circle（宽高独立的椭圆）、teardrop；顺/逆时针非退化凸allowedRegion。整条旋转后轮廓在允许区域和基础域内；minEdgeGap只约束所有复制后切口到真实纸边，折叠边和允许区域边不额外留gap。重叠切口取镂空并集。操作数量受模板更小上限和100条硬上限约束，ID唯一，order连续。

未支持圆纸、horizontal/both、6/8扇区、扇区镜像及非凸区域，返回明确原因。schema允许不等于算法支持。不保证剩余纸张连通、真实刀路或实体可剪性。

算法以M02公式为基线，但无原型运行时依赖。三角精确顶点；椭圆128边外切包络；水滴递归de Casteljau控制凸包；容差集中定义，收敛失败拒绝。曲线距离是保守判断，近边合法曲线可能被拒绝，不能宣称精确距离。原曲线控制点与近似误差完整记录于算法文档。

## 历史与元数据回归

每个方向最多保留30个Work快照，但undo/redo只应用operations和palette。当前id、name、craftId、templateSnapshot、revision、createdAt、updatedAt、status及schemaVersion不回退。核心不负责重命名、保存、修订或时钟。dispatch校验每个历史Work，并比较作品身份与整个模板快照；跨作品、模板版本或同ID/version但内容变化的伪造历史均拒绝。切换模板必须createState。

不同配色和有效剪切写历史/清redo；相同配色、空undo/redo成功无操作，不写历史、不清redo。无效操作不修改任何输入。schema构造独立对象，不使用JSON深复制断言。

验证撤销不改回名称：运行`pnpm m04:test`，查看`undo and redo preserve current name and all save metadata for cuts and palette`：完成剪切和配色后，调用方将当前Work改为“保存后的新名称”、revision=9、更新createdAt/updatedAt和completed状态，保留undo/redo；连续undo两次再redo两次，每步断言所有非创作字段与保存后的当前值完全相同，最后切口及配色恢复。独立测试还覆盖冻结输入、输入/结果/历史间嵌套引用隔离、外部模板变化不污染快照。

## 审核后性能修正：历史重复几何（2026-10-17）

针对P2“每次编辑重复计算全部历史几何”，已修改src/validation.ts和src/history.ts。每次dispatch新建并共享一个按完整模板值/剪切参数值去重的校验上下文；当前作品、历史和新作品中已通过的相同几何只计算一次。每份Work的schema、版本、ID/order、形状尺寸及数量限制仍逐一检查；历史身份和完整模板深值校验不变。只缓存成功键，非法数据不缓存；下一调用重新读取输入值，不信任引用相同或上一次成功，因此可变输入和伪造历史不能绕过校验。缓存不返回数据，没有新增可变引用共享，也没有跨调用保留。

几何成本由全部历史切口总数改为单次调用的不同几何参数组合数；深复制与结构校验仍与历史数据量相关。提前复用基础域/对称矩阵，未改变算法公式、容差或公共接口。完整技术约定补充在算法v1文档。

保留原20项测试，新增7项：50/100个不同角度水滴＋30历史仅计算50/100次几何；100个相同参数不同ID只计算1次；下一次调用篡改历史轮廓仍失败且定位undo.7.operations.3.center；当前几何、历史order、重复ID、模板和跨作品篡改仍拒绝；非法redo仍拒绝；undo/redo同样去重且返回独立数据。测试用计算次数验证重复工作，不设不稳定的毫秒断言。
